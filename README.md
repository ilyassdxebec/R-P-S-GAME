# Rock Paper Scissors 🪨📄✂️

A console-based Rock Paper Scissors game built in C++ where you play against the computer.

## Features
- Choose number of rounds (1-10)
- Play against a computer with random choices
- Color feedback — green for player win, red for computer win, yellow for draw
- Round by round results display
- Final results summary with overall winner

## How to Play
1. Run the program
2. Choose how many rounds you want to play
3. Each round choose: [1] Rock, [2] Paper, [3] Scissors
4. See who wins each round
5. See the final winner after all rounds

## Rules
- Rock beats Scissors
- Paper beats Rock
- Scissors beats Paper

## Built With
- C++
- Visual Studio
